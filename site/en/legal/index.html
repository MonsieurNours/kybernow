Privacy

This website sets no cookies, uses no audience measurement tool and collects no personal data. Fonts, icons and libraries are served by the website itself.

Two exceptions, which serve only you:

  • Your language: the choice you make with the language switch is kept in your browser (local storage), to show you the right version. It is not sent anywhere.
  • The latest version: the home page asks the GitHub API for the number and size of the latest version. Your browser then contacts GitHub, which receives your IP address as it would for any web page.

Links to Discord, GitHub and Kyber lead to third-party websites, subject to their own privacy policies.

The KyberNow software sends nothing to Les Lignes Claires: the image goes directly from your computer to your devices, and the console only contacts GitHub to check for updates.

For any question about your data, or to exercise your rights, write to the contact address above. You can also lodge a complaint with the CNIL (French data protection authority).
