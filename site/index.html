Comment ça marche

De votre ordinateur à votre écran, en six étapes

9,4ms
  1. 01CaptureCopiée depuis l'écran de l'ordinateur, réel ou virtuelt = 0
  2. 02EncodageCompressée par la carte graphique5,19 ms
  3. 03EnvoiDécoupée en paquets chiffrés0,12 ms
  4. 04RéseauTransmise sur le réseau local0,66 ms
  5. 05DécodageDécompressée par votre appareil2,50 ms
  6. 06AffichageÀ l'écran dès qu'elle est décodée0,62 ms

Mesures du 19 octobre 2026 sur un réseau local, d'un PC avec une RTX 3080 Ti vers un MacBook Pro M4 Max. Le trajet complet et chaque étape sont des médianes. Le détail est sur la page Technologie.

Installer

Installez KyberNow en trois étapes

Une app sur votre ordinateur, une autre sur votre appareil, et un code pour les associer.

1 · sur l'ordinateur
Installation de KyberNow Station
Moteur · écran virtuel · manettes · pare-feu KyberNow Station est prête. Admin s'ouvre.
