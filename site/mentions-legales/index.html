Confidentialité

Ce site ne dépose aucun cookie, n'utilise aucun outil de mesure d'audience et ne collecte aucune donnée personnelle. Les polices, les icônes et les bibliothèques sont servies par le site lui-même.

Deux exceptions, qui ne servent qu'à vous :

  • Votre langue : le choix fait avec le sélecteur de langue est gardé dans votre navigateur (stockage local), pour vous afficher la bonne version. Il n'est envoyé nulle part.
  • La dernière version : la page d'accueil demande à l'API de GitHub le numéro et la taille de la dernière version. Votre navigateur contacte alors GitHub, qui reçoit votre adresse IP comme pour toute page web.

Les liens vers Discord, GitHub et Kyber mènent à des sites tiers, soumis à leurs propres règles de confidentialité.

Les logiciels KyberNow ne transmettent rien aux Lignes Claires : l'image va directement de votre ordinateur à vos appareils, et KyberNow Admin interroge seulement GitHub pour connaître les mises à jour.

Pour toute question sur vos données, ou pour exercer vos droits, écrivez à l'adresse de contact ci-dessus. Vous pouvez aussi saisir la CNIL.
