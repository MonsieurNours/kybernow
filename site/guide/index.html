Questions fréquentes

Les questions qu’on nous pose

KyberNow affiche votre ordinateur sur vos autres écrans et vous permet de le piloter, pour jouer comme pour travailler. Vous installez KyberNow Station sur l'ordinateur, puis l'app KyberNow Link sur vos appareils. KyberNow Admin, dans le navigateur, règle la Station, et KyberNow Share fait entrer quelqu'un d'autre. Voir Ce qu'il vous faut pour commencer.
