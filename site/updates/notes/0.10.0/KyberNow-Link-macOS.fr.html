Bêta des comptes KyberNow. Elle n'est proposée qu'aux Stations et aux apps réglées sur les versions bêta.

  • Un compte KyberNow, et vos ordinateurs partout. Créez votre compte sur la page du relais (e-mail et mot de passe, puis une passkey ou la double authentification si vous voulez), connectez-vous dans KyberNow Link, et vos ordinateurs apparaissent à l'accueil, sur tous vos appareils, sans appairage. Sur l'Apple TV, un téléviseur ou la Shield, un code s'affiche : vous l'approuvez depuis votre téléphone. Le compte reste facultatif : le réseau local, l'appairage par code et le partage marchent comme avant.
  • Rattacher votre ordinateur à votre compte. Dans Admin › Compte KyberNow › « Se connecter », ou dès l'installation : l'installateur de la Station, sur PC comme sur Mac, propose une étape « Compte KyberNow », facultative. L'installateur de KyberNow Link pour Windows propose aussi de vous connecter.
  • Ouvrir votre ordinateur à vos proches ou à votre équipe. Sur la page de votre compte, ajoutez une personne par son e-mail et choisissez ce qu'elle peut faire : ouvrir le bureau, emprunter l'ordinateur (le prêt), rejoindre vos partages sans code, ou l'administrer. Pour une équipe, créez une organisation, avec ses membres, ses groupes et un journal de qui a ouvert quoi. Un compte qui peut administrer l'ordinateur ouvre aussi Admin sur le réseau (« Se connecter avec KyberNow »).
  • Inviter un appareil de loin. Admin › Appareils Link › « Inviter un appareil… » donne un code et un mot de passe, valables 1, 7 ou 30 jours. Dans l'app, « Rejoindre avec un code », puis le mot de passe : l'ordinateur s'ajoute, même loin de chez vous, sans que personne ait à l'accepter sur place.
  • Priorité GPU de la capture (PC). Admin › Système › Avancé propose « Priorité GPU » : Normale, Haute (par défaut) ou Temps réel. Si l'image saccade quand un jeu pousse la carte graphique à fond, essayez « Temps réel ».
  • Installateur : il s'ouvre aussi quand Windows demande le mot de passe d'un autre compte administrateur.
  • Relais installé chez vous : les comptes KyberNow demandent une mise à jour du compose. La mise à jour de chaque nuit remplace l'image du relais, pas ses fichiers : la nouvelle image tourne sans rien changer, comptes coupés. Pour activer les comptes, une fois, depuis le dossier du relais : 1. reprenez les fichiers du compose : for f in docker-compose.yml lego.sh update.sh; do curl -fsSLO https://raw.githubusercontent.com/MonsieurNours/kybernow/main/server/relay/$f; done ; 2. créez le dossier des données (la base des comptes et les clés) : mkdir -p data && sudo chown 65532:65532 data ; 3. ajoutez [accounts] et enabled = true dans config/relay.toml, avec la section [accounts.smtp] si vous voulez la vérification par e-mail et le mot de passe oublié (voir relay.toml.example) ; 4. relancez : docker compose pull && docker compose up -d.
