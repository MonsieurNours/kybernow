# KyberNow

Serveur de streaming Windows clé en main et clients macOS / tvOS, construits sur [Kyber](https://kyber.tech). Développé par [Les Lignes Claires](https://www.leslignesclaires.fr).

| Dossier | Contenu |
|---|---|
| `PROJECT.md` | Cadrage et décisions |
| `server/admin/` | Console d'administration (service Windows, Rust) |
| `server/web/` | Interface de la console (Svelte) |
| `server/installer/` | Installateur `KyberNow-Setup.exe` (Rust + WebView2 + Svelte) |
| `brand/` | Logo et déclinaisons |
| `docs/`, `tools/latency/` | Prototype de référence et mesure de latence |
