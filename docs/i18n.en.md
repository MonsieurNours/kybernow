# KyberNow's languages

English · [Français](i18n.md)

Every installer, the console, the tray icon and the clients exist in French and English. Decided on 21/10/2026: automatic detection, manual choice possible, texts in per-language files so that another language can be added without going through everything again.

## Rule

- **System language** (Windows: the user's display language, `GetUserPreferredUILanguages`; Mac and Apple TV: the system's preferred languages; browser: `navigator.languages`): if the first one starts with `fr`, French; **any other language, English**.
- **Manual choice** in each app's settings and in the console: “Auto” (default), “Français”, “English”. It applies to this app on this device only (the app's settings file, the browser's `localStorage` for the console and the web client, the app's `AppleLanguages` on Mac and Apple TV, which needs a relaunch).
- The **installers** have no setting: Windows' language.
- **Logs** (`*.log`, macOS's log) stay in French: they are for diagnosis, not part of the interface.

## Files

- **Web interfaces** (Svelte: console, `/ecran` web client, installers, Windows app, tray panel): `src/lib/i18n/fr.json` and `en.json` (same keys, nested objects per screen), a `t('screen.key', { name })` function that replaces `{name}`, and a reactive language state. French is the source; a key missing in English falls back to French (and shows up in `npm run check` through a test that compares the keys).
- **Rust** (messages of the console, the installer, the Windows app, the core): embedded `fr.json` and `en.json` catalogues (`include_str!`) and a `tr(lang, "key", &[("name", …)])` function. Same fallback rule.
- **Mac and Apple TV**: Xcode string catalogue (`Localizable.xcstrings`), French as the source language, English translation; `developmentLanguage: en` in `project.yml` (hence `CFBundleDevelopmentRegion` set to `en`) so that any untranslated language falls back to English. Deliberate exception to the rule: macOS and tvOS go through the whole list of preferred languages (German then French gives French). `apps/macos/scripts/check-strings.py --fix` gives new texts their explicit French value (without it, Xcode does not write the French file): run it again after any addition.
- A new language: one more file per catalogue (`de.json`, language added to the Xcode catalogue) and its line in the rule above.

## What the server tells devices

- The apps (the Windows app's Rust core, KyberKit on Mac and Apple TV) and the web client send `Accept-Language` with the chosen language (`fr` or `en`) on every request to the console; the console answers in that language (error messages, `verify_error`, refusal reasons, texts meant for the user). Without the header: French (older apps).
- The console itself follows the browser (and its manual choice); the tray icon follows Windows' language.
- The console's **event feed** keeps the event's type and parameters (`key`, `params`; `kind` stays the level, `info` or `warn`) and the sentence is written when read (`GET /api/events`), in the viewer's language. Events recorded before keep their French text.

## Release notes

- `CHANGELOG.md` (French) and `CHANGELOG.en.md` (English) remain the source.
- The GitHub release carries both: the French section, then a `<!-- en -->` line, then the English section. The console, the Windows app and the Updates page take the part in their language (the whole text if there is no marker: releases before 0.3.0, in French).
- The Mac app's Sparkle feed: English as the default description (any language other than French), French as a per-language link (`xml:lang="fr"`) to `site/updates/notes/X.Y.Z/KyberNow-macOS.fr.html`.

## Glossary

The terms already used in the English documents (`*.en.md`) and on `site/en/` are authoritative. Main ones: see the table in [i18n.md](i18n.md#glossaire) (French → English).

Typography: in French, narrow no-break space before “: ; ! ?” and « » quotes as today; in English, no space before punctuation, “ ” quotes, capital letter only at the start of labels (“Connect”, “Keep the last image”). The tone stays the same: short, direct, formal “vous” on the French side.
