# Langues de KyberNow

[English](i18n.en.md) · Français

Tous les installateurs, KyberNow Admin, l'icône et les apps KyberNow Link existent en français et en anglais. Décidé le 21/10/2026 : détection automatique, choix manuel possible, textes dans des fichiers par langue pour qu'une autre langue s'ajoute sans repasser partout.

## Règle

- **Langue du système** (Windows : langue d'affichage de l'utilisateur, `GetUserPreferredUILanguages` ; Mac, Apple TV, iPhone et iPad : langues préférées du système ; navigateur : `navigator.languages`) : si la première commence par `fr`, français ; **toute autre langue, anglais**.
- **Choix manuel** dans les réglages de chaque app et dans Admin : « Auto » (par défaut), « Français », « English ». Il s'applique à cette app sur cet appareil seulement (fichier de réglages de l'app, `localStorage` du navigateur pour Admin et le client web, `AppleLanguages` de l'app sur Mac, Apple TV, iPhone et iPad, qui demande de relancer).
- Les **installateurs** n'ont pas de réglage : langue de Windows.
- Les **journaux** (`*.log`, journal de macOS) restent en français : ils servent au diagnostic, pas à l'interface.

## Fichiers

- **Interfaces web** (Svelte : Admin, client web `/ecran`, installateurs, app Windows, panneau de l'icône) : `src/lib/i18n/fr.json` et `en.json` (mêmes clés, objets imbriqués par écran), une fonction `t('ecran.cle', { nom })` qui remplace `{nom}`, et un état réactif de la langue. Le français est la source ; une clé absente en anglais retombe sur le français (et se voit dans `npm run check` grâce à un test qui compare les clés).
- **Rust** (messages d'Admin, des installateurs, de l'app Windows, du cœur) : catalogues `fr.json` et `en.json` embarqués (`include_str!`) et une fonction `tr(lang, "cle", &[("nom", …)])`. Même règle de repli.
- **Mac, Apple TV, iPhone et iPad** : catalogue de chaînes de Xcode (`Localizable.xcstrings`), français comme langue source, traduction anglaise ; `developmentLanguage: en` dans `project.yml` (donc `CFBundleDevelopmentRegion` à `en`) pour que toute langue non traduite retombe sur l'anglais. Exception assumée à la règle : macOS et tvOS parcourent toute la liste des langues préférées (allemand puis français donne le français). `apps/macos/scripts/check-strings.py --fix` donne leur valeur française explicite aux nouveaux textes (sans elle, Xcode n'écrit pas le fichier français) : à relancer après tout ajout.
- Une nouvelle langue : un fichier de plus par catalogue (`de.json`, langue ajoutée au catalogue Xcode) et sa ligne dans la règle ci-dessus.

## Ce que la Station dit aux appareils

- Les apps (par le cœur Rust : Windows, Mac, Apple TV, iPhone et iPad) et le client web envoient `Accept-Language` avec la langue choisie (`fr` ou `en`) à chaque requête vers Admin ; Admin répond dans cette langue (messages d'erreur, `verify_error`, raisons de refus, textes destinés à l'utilisateur). Sans en-tête : français (anciennes apps).
- Admin lui-même suit le navigateur (et son choix manuel) ; l'icône suit la langue de Windows.
- Le **fil des événements** d'Admin garde le type de l'événement et ses paramètres (`key`, `params` ; `kind` reste le niveau, `info` ou `warn`) et la phrase est écrite à la lecture (`GET /api/events`), dans la langue de qui regarde. Les événements enregistrés avant gardent leur texte français.

## Notes de version

- `CHANGELOG.md` (français) et `CHANGELOG.en.md` (anglais) restent la source.
- La release GitHub porte les deux : la section française, puis une ligne `<!-- en -->`, puis la section anglaise. Admin (page Mises à jour) et l'app Windows prennent la partie de leur langue (tout le texte s'il n'y a pas de marqueur : versions d'avant la 0.3.0, en français).
- Le flux Sparkle de l'app Mac : l'anglais en description par défaut (toute langue autre que le français), le français en lien par langue (`xml:lang="fr"`) vers `site/updates/notes/X.Y.Z/KyberNow-macOS.fr.html`.

Première mention dans un écran ou une page : « KyberNow Station », « KyberNow Admin », « KyberNow Link » ; ensuite « la Station », « Admin », « l'app ». Kyber (le moteur de streaming, service `kyber`) reste Kyber, pas la Station. En anglais, « link » désigne aussi le lien `kybernow://` : préférer « pairing link », « connection quality » quand un texte deviendrait ambigu. Les identifiants techniques ne changent pas (`kyber-admin`, `console` dans le code, `kybernow://`, dossiers `KyberNow`).

Typographie : en français, espace fine insécable avant « : ; ! ? » et guillemets « » comme aujourd'hui ; en anglais, pas d'espace avant la ponctuation, guillemets “ ”, majuscule seulement au début des libellés (« Connect », « Keep the last image »). Le ton reste le même : court, direct, en vouvoiement côté français.
